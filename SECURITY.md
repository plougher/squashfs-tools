Please open issues on https://github.com/plougher/squashfs-tools/issues

Do NOT send security issues to any of my private email addresses
(phillip@squashfs.org.uk, phillip.lougher@gmail.com etc.) because
these wil be either ignored, or you'll get a request to raise it
as an issue here.

There are two reasons for this:

1. Squashfs-tools is an open project and I don't do secret discussions.

2. If multiple people email me privately about an issue, then it is impossible to prove who emailed me first, or if I discovered the issue myself whilst fixing or investigating another security issue.

Whenever anything is done in secret, truth can become variable.  I have absolutely no interest in going there.
